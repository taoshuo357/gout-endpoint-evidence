# Third-party software and data

Bundled software consists of project-authored wrappers/orchestration and the independent public figure layer. Installed libraries and official implementations are not bundled. scTenifoldKnk2.0.0 e003c72d3a153ec07512271c1ae0fbeeadc319ca and scTenifoldNet1.4.3 3103a53216c347a3d4c9660d63b03c2ca99b47a1 declare GPL>=2. coloc6.0.3 27776b1bb14e19d1542798ac7477fa378fc2fc0d declares GPL without specifying a version in DESCRIPTION. The project wrappers' MIT grant does not relicense these dependencies or remove obligations when combining/redistributing components. Official mmseq/coloc source functions are called from external paths, not copied here. limma/edgeR, decoupler/LIANA, numpy/scipy/pandas/matplotlib/networkx, scikit-learn/RDKit, OpenMM/Vina and other installed dependencies are separately obtained under original terms.

No private skill/QC implementation is bundled. atlas_style.py/resolver.py are independently project-authored. A05's historical private QA import is a reference in an archival script, not a bundled implementation/public execution entry point.

Data are outside MIT. ChEMBL adaptations retain BY-SA3; public protein Zenodo23181166v3 adaptations retain BY-NC4; PLOS Quercetin S1 numerical data retain the article attribution grant. STRING and AlphaFold DB outputs retain BY4; PDB archived coordinates CC0. Other integrated source data retain original terms. PubChem/GEO contributions are not automatically public domain. Source-specific uncertainty is an explicit member-level HOLD, not a grant. See licensing/ for attribution, evidence and concrete replacement/exclusion lists. No source-data ZIP or private patient workbook is in this code archive.
